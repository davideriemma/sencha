> A human is present and runs every command that needs a password.

## How to work (read this first, every task)

1. **Do only the phase you were asked to do.** Stop at the end of the phase and call
   `attempt_completion`. Do not start the next phase.
2. **One command per step.** Run the command exactly as written. Do not rewrite it, shorten it
   or "improve" it. Use absolute paths.
3. **Every step has Expected and If not.** If the output does not match **Expected**, do what
   **If not** says. Never invent a fix.
4. **STOP means:** call `ask_followup_question` with the failing command and its last 40 lines of
   output, then wait. Do not try another approach.
5. **Show proof.** Never write "done" or "passed" unless the command output that proves it is in
   the conversation.
6. **Forbidden, always:**
   - `sudo`, installing Homebrew, `brew install`, `git commit`, `git push`, `git pull`, `git fetch`
   - editing anything under `/Users/davideriemma/Desktop/LITEX/litex/`
   - editing `minimal_soc.py`
   - deleting anything that is not listed in Phase 2
   - editing other files except with the exact text given in this plan
7. **Report.** At the end of each phase append one line to
   `/Users/davideriemma/Desktop/LITEX/output/M0_report.md` (create it in Phase 1):
   `| Phase N | pass / fail / STOP | key output line |`.
